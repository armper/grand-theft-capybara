# Grand Theft Capybara

A pet detective mystery in the sunny city of Bahia Rosa: find Don Capy, the missing capybara. Runs in the browser (Chrome or Edge on a desktop).

**Play:** https://armper.github.io/grand-theft-capybara/

This repository holds only the packaged web build, published with GitHub Pages. Controls: WASD to move, Shift to run, Space to jump, E to talk and use things, Tab for the notebook, M for the map, P to pause; hold a mouse button and drag to look around.

Made with Unreal Engine. Third-party material is listed in CREDITS.md.
